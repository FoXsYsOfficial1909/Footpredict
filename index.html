      Архивы v1 и v2 содержат разные матчи. Их общие проценты не определяют, какая модель лучше; для этого используется сравнение ниже.

      Разбор результатов

      Открой матч, чтобы увидеть исходные вероятности, счёт и величину ошибки.

      Как читать показатели

      «Совпал исход» — как часто единственный наиболее вероятный вариант П1 / Х / П2 совпал с итогом. Равные максимумы исключаются из этого процента и отмечаются отдельно. Ошибка такого выбора не означает, что модель обещала исход со стопроцентной вероятностью.

      Brier оценивает все три вероятности: сумма квадратов ошибок, от 0 до 2. Log Loss оценивает вероятность случившегося исхода и сильнее штрафует уверенные ошибки. Для обоих меньше — лучше. Для нулевой вероятности в Log Loss используется нижняя граница 10⁻¹².

      Показываем последние сохранённые результаты сверки. Переносы, отмены, разногласия в счёте и неполные записи исключаются из общего сравнения. Исторический эксперимент оценивается отдельно. Маленькая выборка не доказывает будущего преимущества модели.

        Для Brier и Log Loss меньше — лучше. База — сохранённые частоты исходов лиги, а не букмекерские коэффициенты. Десять матчей — малая выборка, не доказательство будущей точности. Отчёт читает сохранённые данные и не запускает прогнозы или сверку.

        Локальные записи неподтверждённые и не смешиваются с серверной серией из 10 матчей. Её отчёт доступен в режиме «На сервере».

        Запись закрывается за 5 минут до начала матча. Серверная автосверка запускается раз в 2 часа, не раньше чем через 4 часа после начала матча, до 5 записей за запуск. При очереди или лимите API обновление может задержаться. Кнопка «Сверить результат» позволяет проверить вручную. Чтобы увидеть обновления, нажми «Загрузить историю» или обнови страницу. Локальная история автоматически не сверяется. Переносы и спорные результаты исключаются из оценки.

        Историческая проверка

        Каждый матч прогнозируется по результатам, доступным до его начала. При проверке трёх сезонов первые два помечаются как период разработки, последний — как контрольный период. Алгоритм и его параметры одинаковы для всех сезонов, автоматически не обучаются и не подгоняются под эти результаты.

        ⚠ Контрольный сезон здесь не является полностью независимым и нетронутым тестом: мы уже анализировали его в предыдущих версиях. Это отдельный временной срез, а не гарантия будущей точности. Честный следующий шаг — оценка новых матчей по мере их завершения.
