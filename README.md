# Footpredict

Футбольная аналитика и прогнозы. Интерфейс на русском, статический сайт без сборки.

- Приложение: https://foxsysofficial1909.github.io/Footpredict/
- API: https://footpredict-api.wzjp5747md.workers.dev
- Backend: Cloudflare Worker, D1, KV и Workers AI. Ключи поставщиков хранятся на сервере.

## Запуск

Нужны Python 3.12+ и Node.js 24+ для проверок. Самому интерфейсу достаточно HTTP-сервера:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Точный локальный origin разрешён в API. Другие порты и посторонние origins не разрешены.

Для исследовательских инструментов и браузерной проверки в облачной среде:

```bash
bash scripts/setup.sh
source /workspace/.venvs/footpredict/bin/activate
```

Скрипт сохраняет настройки прокси и проверку TLS. Импорт публичного сертификата среды в Chromium необязателен для старта; перед HTTPS-проверкой браузера он должен успешно выполниться. Chromium и certutil предоставляет образ среды.

## Автоматическая работа

Сбор и отчёты выполняются в Cloudflare при закрытом приложении и отключённой рабочей среде. Очередь, время следующей попытки и результаты хранятся в D1. После прерывания аренда задачи истекает, и её может продолжить следующий запуск. Ошибка одного источника не блокирует остальные виды задач.

- Рабочий запуск: в минуты 07 и 37 каждого часа UTC. За запуск обрабатывается ограниченная часть очереди.
- Существующий триггер проверки результатов сохранён: `17 */2 * * *`.
- Ежедневный отчёт: `50 4 * * *`, то есть 07:50 МСК. При пропуске формируется при следующем запуске с фактическим временем и отметкой задержки.
- Примерный интервал проверки клубных лент — 2 часа. Карточки матчей обновляются по очереди с учётом близости матча и квот.
- Лимиты приложения: 12 сборов карточек и 4 вызова ИИ в сутки. Дневной сброс — 00:00 UTC / 03:00 МСК. Бюджеты поставщиков и KV также действуют.

В приложении доступны состояние сбора, ежедневный отчёт с JSON-экспортом и отдельная история v2. Отправка сообщений в мессенджеры не настроена.

## Модели и данные

Основная модель — `poisson-1.0.0`. Её сохранённая история остаётся отдельной. Экспериментальная v2 сочетает обучаемую модель атаки/защиты и Elo. Вероятности v2 фиксируются минимум за 24 часа до матча; итоги оцениваются по этим вероятностям с отдельными наблюдениями результатов. Переносы и изменения идентичности матча требуют проверки.

Новости, травмы и составы **не используются в вероятностях v2**. Источник травм API-Football на текущем бесплатном тарифе не открывает сезон 2026; отсутствие данных не означает отсутствие травм. Официальные составы и полный календарь всех турниров не гарантируются. У v2 пока нет автоматического переобучения или повышения до основной модели.

Разбор дополняют короткие сообщения клубов и прессы о доступности игроков. Официальные новостные страницы проверяются отдельной очередью примерно раз в 12 часов, постепенно для всех текущих клубов. Цитаты доступны и без ИИ; новый ИИ-разбор выбирает готовые фрагменты по номеру. Он не генерирует исходную цитату или URL. Обзор источников, ограничения и способы проверки описаны в [сводках о доступности](docs/availability.md).

Историческая проверка: [карточка модели](docs/model-card.md). Проверка исходной серии: [аудит результатов](docs/results-audit.md). Архитектура, API и восстановление: [автоматическая работа](docs/automation.md).

Раздел [«Качество прогнозов»](https://foxsysofficial1909.github.io/Footpredict/#qualityDashboard) показывает размер выборки, долю совпадений, Brier и Log Loss, сравнение на общих матчах и разбор ошибок. Исторический эксперимент доступен отдельным режимом. Открытие раздела читает только сохранённые данные. Определения, исключения и API: [оценка качества](docs/quality.md).

## Проверки

```bash
python3 -m unittest discover -s tests
node --test tests/*.test.mjs
```

Node-тесты очереди исполняют настоящий SQLite через `node:sqlite` и проверяют восстановление после прерывания, исключение одновременного выполнения, временные ограничения, неизменность вероятностей и независимость задач при ошибке.

Браузерная проверка требует запущенного локального сервера, Playwright, Chromium и доверия к публичному CA среды:

```bash
python3 scripts/trust_browser_ca.py
python3 tests/browser_smoke.py
python3 tests/browser_quality.py
```

Она обращается к действующему API и может запустить ограниченный сбор карточки. Общие прогнозы v1 не создаёт. Не запускайте её часто без изменений: действуют квоты поставщиков.

`browser_quality.py` проверяет новый экран, фильтры, экспорт, обработку отказа и мобильную вёрстку. Он читает только серверный архив и не запускает сбор или сверку.

## Публикация Worker

Используются уже настроенные `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN`. Значения секретов не копируются в репозиторий или интерфейс.

```bash
python3 -m scripts.deploy_worker --backup-dir /workspace/scratch/footpredict-deployment-review
# После проверки: тот же вызов с новым каталогом и --apply.
python3 -m scripts.configure_automation --backup /workspace/scratch/footpredict-schedules-review.json
# Для применения расписаний: новый путь резервной копии и --apply.
```

Загрузка сначала сохраняет резервную копию, проверяет отсутствие параллельных изменений, затем сверяет опубликованные исходники побайтно и проверяет сохранность настроек. Добавление расписаний сохраняет существующие триггеры. Обычный запуск среды ничего не переопубликовывает.
