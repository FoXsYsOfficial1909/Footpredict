# Отдельное обучение Чемпионшипа

Архив Football-Data.co.uk E1 расширен до 12 сезонов, 2015/16–2026/27: **6 252 проверенных матча** на 14 ноября 2026. В каждом из 11 завершённых сезонов — 552 игры регулярного чемпионата; в текущем — 180. Плей-офф и игры других лиг в этот источник не добавляются.

Источник: [Football-Data.co.uk](https://www.football-data.co.uk/englandm.php). Для каждого CSV сохранены URL, SHA-256, даты и количество результатов. Загрузчик проверяет код дивизиона E1, сезон, команды, уникальность матчей и согласованность счёта с исходом. Для АПЛ используется отдельный код E0 и отдельные файлы кэша.

Модель использует прошлые результаты, силу атаки и защиты, силу соперника, преимущество своего поля и Elo. Архив содержит также ставки и послематчевую статистику; они не становятся признаками прогнозируемой игры. Окно Пуассона — последние 1 095 дней, поэтому все 6 252 игры не используются одновременно в одной подгонке. Более старая история также нужна для последовательного Elo и воспроизведения ранних контрольных прогнозов.

Настройки выбраны на **1 061 общем матче сезонов 2023/24 и 2024/25**, из 1 104 возможных. Сравнено 18 заранее ограниченных сочетаний: три периода затухания, два уровня регуляризации и три веса Пуассона в смеси с фиксированным Elo. Выбранный рецепт сохранён до расчёта следующих периодов: половинное затухание 730 дней, регуляризация 0,03, 75% Пуассона и 25% Elo.

Проверка после выбора:

| Период | Общих матчей | Модель | Brier ↓ | Log Loss ↓ | Совпал исход |
| --- | ---: | --- | ---: | ---: | ---: |
| 2025/26 | 533 | Кандидат | 0,642136 | 1,063151 | 45,0% |
| 2025/26 | 533 | v1 | 0,645334 | 1,066056 | 42,8% |
| 2026/27 | 159 | Кандидат | 0,654572 | 1,079895 | 41,5% |
| 2026/27 | 159 | v1 | 0,632384 | 1,049836 | 48,4% |

Критерий улучшения **не выполнен**. В текущем сезоне кандидат хуже v1; интервалы общего отличия предыдущего сезона пересекают ноль. Прежний рецепт АПЛ, переобученный на тех же расширенных данных, также оказался лучше выбранного кандидата по вероятностным ошибкам обоих поздних периодов. Это не основание заменять основную модель. [Полный отчёт](research/championship-2026-11-14/report.md) содержит сравнения, интервалы и разбор ошибок, включая реальные доли исходов и самые большие ошибки вероятностей.

Это ретроспективное исследование. Недавние сезоны уже частично изучались в предыдущем опыте четырёх лиг; они не объявляются независимым будущим тестом. Для всех сравниваемых моделей CSV-проверки исключены результаты самого дня матча и непосредственно предыдущего дня. Датовый вариант v1 не совпадает в точности с онлайн-прогнозом, использующим время начала до секунды. Исходная серия из 100 будущих матчей сохраняет прежние вероятности и источники.

## Ежедневное обновление

[Существующее расписание ночного обучения](../.github/workflows/nightly-training.yml) теперь включает отдельное задание `championship`: ежедневно в 00:23 UTC / 03:23 МСК, при подходящем изменении кода или по ручному запуску workflow. Для работы задания открывать сайт не нужно.

Задание обновляет текущий сезон E1, проверяет полную историю, обучает веса с уже выбранными настройками и сохраняет последние исторические контрольные прогнозы. Полный перебор 18 вариантов каждый день не повторяется. Файл настроек проверяется по контрольной сумме исходного исследования. Веса и отчёт явно сохраняют неуспешный статус исторического критерия; ежедневное обновление не превращает его в доказанное улучшение.

Результаты публикуются отдельно в ветку `championship-training-reports`: `latest.json`, версии наблюдений и файлы моделей под SHA-256. Архив АПЛ `training-reports` сохраняет свою модель. Проверки запрещают публиковать веса одной лиги как модель другой. При отказе источника или сохранения артефакта новая попытка отмечается неуспешной; предыдущий успешный файл остаётся доступен.

Эта модель пока не подключена к публичным вероятностям и не имеет отдельной зарегистрированной будущей серии. Ночной отчёт оценивает историческую процедуру, а не будущую точность новых финальных весов.

## Воспроизведение

В [каталоге исследования](research/championship-2026-11-14/) сохранены выбранные настройки, все 18 результатов отбора, поздние прогнозы, разбор ошибок, манифест и нормализованный архив результатов. В архиве `training-data.json.gz` каждый элемент имеет поля `[дата, сезон, хозяева, гости, голы хозяев, голы гостей]`; исходные послематчевые столбцы не нужны.

Повторение исследования по сохранённому архиву без сети:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m research.championship experiment \
  --snapshot docs/research/championship-2026-11-14/training-data.json.gz \
  --output /tmp/footpredict-championship-replay --as-of 2026-11-14
```

Архив проверяется по хешам сжатого и исходного JSON, датам, идентичности матчей и нормализованным данным. Обучение на свежих CSV и обновление зафиксированного кандидата:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m research.championship experiment \
  --data-dir data/championship --output /tmp/footpredict-championship-study
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m research.championship refresh \
  --data-dir data/championship --output /tmp/footpredict-championship-candidate
```

Эксперимент в `/tmp` не заменяет сохранённые настройки ежедневного задания. Основная модель приложения и исходные 100 прогнозов этими командами не изменяются.
