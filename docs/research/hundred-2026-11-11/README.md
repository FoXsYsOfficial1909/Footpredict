# Зафиксированная серия: 100 будущих матчей

Все 100 вероятностей П1 / Х / П2 сохранены **11 ноября 2026, 20:40:07 МСК**, до начала всех выбранных игр. Первые матчи — 15 ноября по Москве; последний — 29 ноября. Минимальный фактический запас до начала — более 75 часов.

| Лига | Матчей |
| --- | ---: |
| Англия, Чемпионшип | 36 |
| Бразилия, Серия А | 26 |
| Англия, АПЛ | 20 |
| Испания, Ла Лига | 18 |

Выбраны первые 100 пригодных будущих матчей этих четырёх лиг по UTC времени начала, затем коду лиги и ID. Уверенность модели не использовалась для отбора. Порог регистрации — минимум 24 часа; максимальное окно — 45 дней. Все выбранные игры укладываются в 19 дней от регистрации. Поле `skipped` сохраняет причины исключения из-за недостаточной истории; в этой серии оно пустое.

Модель — действующая базовая `poisson-1.0.0`. Для каждой лиги использована её собственная история 2025 и 2026 сезонов, без смешивания команд и средних разных чемпионатов. Счёт — за основное время с добавленными минутами. Текущие травмы, составы, погода и экспериментальная поправка здесь не используются. Это отдельная проверка базовых вероятностей, а не сто новых примеров для модели травм АПЛ.

- [Все 100 прогнозов, CSV](forecasts.csv)
- [Исходный снимок с полными вероятностями](packet.json)
- [SHA-256 снимка](packet.sha256)
- `inputs/` — неизменные исходные завершённые матчи для воспроизведения.

Контрольная сумма JSON:

```text
115bccbb92bcb85c69e4141d50d86cc185c70a62fdfbad6e2630517db820b39d
```

У каждого прогноза есть ID матча и команд, лига, время начала, три вероятности, простая база по частотам лиги, ожидаемые голы и параметры расчёта. Манифест источников содержит URL, время наблюдения и хеши ответов. Четырёхчасовой барьер исключает незавершённые или только начавшиеся исторические игры. `scripts/freeze_hundred.mjs` использует ту же функцию расчёта, что и Worker; команда отказывается переписывать существующую серию. Независимая Python-проверка воспроизводит все 100 распределений по исходным данным.

```bash
python -m research.hundred verify
```

Автосверка [запускается каждые шесть часов](../../../.github/workflows/hundred-results.yml). Она читает четыре общих календаря, не пересчитывает вероятности и не создаёт по запросу на каждый матч. Результат принимается после статуса FINISHED и минимум четырёх часов от начала, при совпадении лиги, сезона, ID, команд, исходного времени и счёта основного времени. Перенос, отмена, замена команд или неясный счёт остаются на проверке и не входят в метрики. Исключённые игры не заменяются другими.

Наблюдения результатов публикуются отдельно в ветке `hundred-results`: последний отчёт и неизменные полные версии проверок. Ошибка источника сохраняет предыдущий успешный отчёт с явной отметкой. Будущие исправления счёта могут изменить оценку результата, но не исходный прогноз.

После завершения серии предусмотрено окно 14 дней на исправления поставщика. Затем серия архивируется; последующие запуски больше не обращаются к поставщикам и сохраняют дату последней настоящей сверки.

Показываются число завершённых матчей, Brier, Log Loss и совпадение наиболее вероятного исхода, с одинаковым набором матчей для модели и простой базы. Есть раздельная разбивка по лигам. Пока результатов нет, точность и ошибки равны `null`, а не нулю. Старые серии и основная история не переписываются.

Данные этой серии можно использовать для исследования ошибок и последующего обучения следующих версий. Точность модели, дообученной на результатах этих же матчей, нельзя выдавать за независимую проверку этой сотни.
