# Экран качества прогнозов

Раздел «Качество» читает сохранённые вероятности и последние наблюдения результатов из D1 через `GET /v1/quality`. Открытие и обновление экрана не запускает сбор, прогноз, сверку, обучение или запрос к поставщику. Токен владельца не требуется; действуют обычные ограничения origin. Неизвестные параметры запроса отклоняются.

Сводки учитывают весь архив основной `poisson-1.0.0` и текущей экспериментальной версии. В v1 могут быть разные лиги; они перечислены на карточке. Архивы имеют разный состав матчей, поэтому их общие проценты не используются для выбора победителя. Модель другой версии не включается автоматически в эту оценку.

Прямое сравнение v1, v2 и простой базы использует только общие матчи с одинаковыми командами, лигой, временем начала и подтверждённым счётом основного времени. Оба прогноза должны быть сохранены минимум за 24 часа. Отсутствующая база исключает запись из всех трёх столбцов этого сравнения. Время сохранения может различаться: это ещё не эксперимент с полностью одинаковой доступной информацией.

Для отдельного архива v1 действует исходное предматчевое ограничение 5 минут; для v2 — 24 часа. Для результата нужны целые неотрицательные голы и время проверки не раньше четырёх часов после начала. Переносы, отмены, неполные записи и разногласия в счёте видны отдельно. Берётся последнее наблюдение по последовательности записи, поэтому исправление результата может изменить метрики. Исходные прогнозы не меняются.

Метрики пересчитываются из сохранённых вероятностей, а не из готового значения в наблюдении:

- Brier — сумма квадратов ошибок трёх исходов, от 0 до 2.
- Log Loss — натуральный отрицательный логарифм вероятности фактического исхода; нижняя граница вероятности — 10⁻¹².
- Доля совпадений — единственный наиболее вероятный исход против фактического. Разница максимумов до 10⁻¹² считается равенством. Равные максимумы остаются в Brier и Log Loss, но исключаются из знаменателя доли совпадений; число таких записей показывается.

Пустая выборка имеет размер 0 и метрики `null`, а не нулевую ошибку. Фильтр ошибок показывает только несовпадение единственного максимума, сортируя по его вероятности. В нём нет ожидающих результатов или равных максимумов. Фильтры меняют разбор матчей, а сводки остаются полными.

Ответ содержит не более 200 последних матчей для разбора; это ограничение явно отмечено, если архив больше. Сводки вычисляются по всему архиву указанных версий. Кнопка JSON экспортирует тот же отчёт с временем формирования и областью покрытия. При ошибке обновления старые данные сохраняются с явной датой, первый неудачный запрос не создаёт нулевую статистику.

Исторический эксперимент 2025/26 доступен отдельным режимом: 369 общих матчей из 380. Это последовательные исторические обучения, а не результат текущего фиксированного набора весов. Ограничения описаны в [карточке модели](model-card.md). Данные новостей и травм пока не влияют на вероятности; автоматического переобучения или повышения v2 до основной версии нет.
