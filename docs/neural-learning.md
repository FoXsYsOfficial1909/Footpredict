# Первая нейросеть: реальные результаты и ограничения

16 ноября 2026 года обучена небольшая остаточная сеть: **56 признаков → 16 tanh-нейронов → три исхода**, всего **963 параметра**. Она добавляет поправку к логарифмам вероятностей прежней модели Пуассона и нормирует результат softmax. П1/Х/П2 суммируются до единицы. Это настоящая подгонка весов по результатам, а не повторный запуск расчёта статистики.

Рецепт, временные границы, главная метрика **Log Loss**, пять возможных весов смеси и критерий допуска сохранены [до расчёта футбольных метрик](research/neural-plan-2026-11-16.json). Архитектура, seed и регуляризация после результата не менялись. [Полный машинный отчёт](research/neural-2026-11-16/report.json) содержит вероятности, калибровку отдельно для П1/Х/П2 и результаты по каждой лиге.

## Данные и разделение

Проверенный снимок football-data.co.uk содержит **14 002 завершённых игры**: АПЛ — 4 280, Чемпионшип — 6 252, League One — 3 470. Для первых двух лиг история начинается в 2015 году, для третьей — в 2020-м. Последние доступные игры снимка: 8 ноября, 7 ноября и 4 ноября соответственно. Это описание конкретного архива, а не обещание полноты текущих данных.

| Назначение | Сезоны | Матчей |
| --- | --- | ---: |
| Только начальная история признаков | 2015/16 | 932 |
| Оценка ранних весов | 2016/17–2022/23 | 8 180 |
| Выбор веса смеси | 2023/24–2024/25 | 2 968 |
| Поздняя историческая проверка | 2025/26 | 1 484 |
| Исторический мониторинг | Доступная часть 2026/27 | 438 |

Нормализация признаков оценивается только по обучающим строкам. Матчи имеют временное взвешивание с полураспадом 730 дней; каждая лига получает треть общей массы. По ранней проверке выбран вес сети 1,0 из заранее заданных `[0; 0,25; 0,5; 0,75; 1]`. Затем та же сеть заново обучена на **11 148** играх 2016/17–2024/25 и без изменения проверена на двух поздних периодах.

Все признаки используют игры строго раньше предыдущего дня UTC относительно матча. Собственный результат, будущая таблица и поздние новости в признаки не входят. Используются голы, удары и удары в створ, домашние/выездные результаты, форма, Elo, индикаторы доступности статистики и лиги. Интервал после предыдущей игры лиги не называется полным отдыхом команды: игры кубков в этих данных отсутствуют.

Ни одна из 4 890 проверяемых игр не удалена из основного сравнения. Если v1 не может рассчитать вероятность из доступной истории домашней/выездной игры, применяется явно отмеченная база прошлых частот лиги. Таких случаев: 118 в выборе смеси, 54 в поздней проверке и 55 в мониторинге. В отчёте также есть отдельное сравнение **только общей выборки с доступной v1**, одинаковой для всех моделей.

## Качество

Ниже Log Loss и Brier — среднее трёх метрик лиг с равным весом (**macro**), попадания — доля по всем играм. «Прежняя» — v1 с описанной подстановкой частот при нехватке истории. «Частоты» — только прежние частоты П1/Х/П2 соответствующей лиги. Все модели оцениваются на одинаковых матчах.

| Период | Модель | Log Loss ↓ | Brier ↓ | Попадания |
| --- | --- | ---: | ---: | ---: |
| 2025/26 · 1 484 игры | Прежняя | 1,058054 | 0,638028 | 45,55% |
| | Нейросеть | **1,036891** | **0,623991** | 46,56% |
| | Частоты | 1,080565 | 0,653926 | 43,53% |
| 2026/27 · 438 игр | Прежняя | 1,082209 | 0,655427 | 41,78% |
| | Нейросеть | **1,051296** | **0,633495** | 46,12% |
| | Частоты | 1,089250 | 0,660256 | 42,47% |

Для Log Loss меньше означает меньше штраф за уверенный неверный прогноз. Используется натуральный логарифм: среднее `−ln(max(p_фактического_исхода, 1e−12))`. Brier — средняя **сумма трёх** квадратов ошибок `Σ(p_k − y_k)²`, шкала **0–2**, без деления на три. Попадание — совпадение единственного наиболее вероятного исхода с фактом; равные максимумы учитываются отдельно. В этих сравнительных таблицах равных максимумов нет.

Для прямого сравнения с доступной v1 на 383 общих играх мониторинга: **v1 Log Loss 1,076319 / Brier 0,651306 / 42,56%; сеть 1,051152 / 0,633242 / 47,00%; частоты 1,084366 / 0,656964 / 43,34%**. Здесь метрики обычные, по объединённым матчам, поэтому их нельзя смешивать с macro-строками выше. Охват общей v1 — 383/438; остальные 55 игр остаются в полном сравнении с явной подстановкой.

Калибровка по всем 438 играм мониторинга:

| Исход | Средняя вероятность прежней модели | Средняя вероятность сети | Фактическая частота |
| --- | ---: | ---: | ---: |
| П1 | 42,76% | 43,24% | 42,47% |
| Х | 25,17% | 25,11% | 27,40% |
| П2 | 32,07% | 31,65% | 30,14% |

Средняя вероятность сама по себе не доказывает хорошую калибровку. В отчёте сохранены также десять диапазонов вероятностей для каждого исхода с числом игр, средней вероятностью, фактической долей и интервалом Wilson. Ошибка калибровки ECE сети для П1/Х/П2 — 5,30 / 2,29 / 2,35 процентного пункта; прежней модели — 5,22 / 2,55 / 2,18. Калибровка не улучшилась одинаково по всем исходам; ничьи в среднем всё ещё недооценены.

Средний прирост не одинаков по лигам:

| Мониторинг 2026/27 | Игр | Прежний Log Loss | Нейросеть |
| --- | ---: | ---: | ---: |
| АПЛ | 100 | 1,083896 | 1,038253 |
| Чемпионшип | 180 | **1,056778** | 1,069975 |
| League One | 158 | 1,105953 | 1,045661 |

**Исторический критерий допуска не пройден:** сеть ухудшила Log Loss Чемпионшипа. Предусмотренная проверка требует отсутствия такого ухудшения в каждой лиге обоих поздних периодов. Парный bootstrap календарных дней, 1 500 повторов, даёт для macro-разницы сети и прежней модели 95% интервалы `[-0,031092; -0,012126]` в 2025/26 и `[-0,057122; -0,005956]` в мониторинге. Они описывают неопределённость этого исторического сравнения; история уже изучалась при разработке и независимым тестом не является.

Обе исторические подгонки дошли до лимита **200 итераций**; `converged:false`, `stopReason:iteration_limit`. Это ограниченные конечные веса, а не доказанная сходимость оптимизатора. Бюджет после просмотра качества не увеличивался.

## Что работает дальше

Основная вероятность приложения и прежние будущие пакеты сохранены. [Автотренеры](trainer-agents.md) обучают окончательные исследовательские веса на допустимой новой истории и ведут отдельный журнал будущих матчей АПЛ. Это разрешённый эксперимент кандидата после непройденного исторического допуска, **не обход допуска в основной продукт**. Новые финальные веса не получают исторические показатели сети, обученной на другом периоде.

Вывод: исторический средний прирост есть, устойчивое улучшение для всех лиг и на новых играх **не подтверждено**. Нужны реальные исходы заранее сохранённых прогнозов. Эти матчи могут пересекаться с прежними исследованиями, поэтому число независимых игр не увеличивается от числа моделей.

## Воспроизведение

```bash
python -m pip install -r requirements-research.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m research.neural_experiment \
  --feature-cache docs/research/neural-2026-11-16/feature-rows.json.gz \
  --output /tmp/footpredict-neural
```

Без `--feature-cache` признаки полностью пересчитываются из проверенного снимка. Кэш проверяется по контрольным суммам исходных признаков и генерирующего кода, идентификаторам матчей, результатам и временным границам. Сохранены план, ранние и повторно обученные веса, выбор смеси, вероятности всех проверок, калибровка и хеши данных. Финальная исследовательская сеть хранится отдельно в журнале автотренеров.
